# Linux Network & Server Administration Lab

## Project Topic

This project is a practical Linux administration
and networking lab built using VirtualBox.

## Lab Environment

- Ubuntu Desktop: Server machine
- Kali Linux: Client machine
- VirtualBox: Virtualisation platform

## Project Objectives

- Practise Linux system administration.
- Configure users, groups and file permissions.
- Understand IP addressing and network connectivity.
- Configure and manage SSH.
- Host a web server.
- Practise firewall management.
- Write basic Bash automation scripts.

## Progress

- [x] Virtual machines installed.
- [x] Network adapters configured.
- [x] Internal network IPv4 configuration.
- [x] User and group management.
- [x] SSH server configuration.
- [X] Web server deployment.
- [X] Firewall configuration.
- [X] Bash automation.
